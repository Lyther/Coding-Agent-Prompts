# Antigravity adapter

Render canonical skills to Antigravity's user skill root and keep the available high-impact commands as legacy manual workflows.

Default user install target:

- `~/.gemini/config/skills/<name>/SKILL.md`
- reviewed external packs under `~/.gemini/config/skills/`
- `~/.gemini/antigravity/global_workflows/*.md`

Google announced that consumer Gemini CLI users should migrate to Antigravity CLI by June 18, 2026. The latest CLI plugin package is generated by the separate `antigravity-cli` target.

Native MCP support is not generated for this desktop target; local optional-service wiring remains host-owned.
